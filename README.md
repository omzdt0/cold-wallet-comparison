## 先搞懂：冷錢包和熱錢包差在哪裡？

「冷錢包」與「熱錢包」的核心差別，不在品牌，而在**私鑰是否長時間接觸網路環境**。

### 冷錢包

冷錢包通常指私鑰在離線環境中生成、保存或簽署交易的錢包。最常見的形式是硬體錢包，也有人使用專用離線設備或紙本備份。

硬體錢包的基本流程通常是：

1. 裝置在本機生成私鑰和助記詞。
2. 私鑰留在硬體設備內，不直接交給手機或電腦。
3. 使用者在手機或電腦建立交易。
4. 硬體錢包在裝置上確認並簽署交易。
5. 已簽署的交易再傳回網路廣播。

這樣的設計可以降低惡意軟體、瀏覽器外掛或釣魚網站直接取得私鑰的機會。OKX 自己的硬體錢包指南也將硬體錢包描述為離線保存私鑰的實體設備，並指出它適合長期保存較大量的加密資產。

### 熱錢包

熱錢包是連接網路的軟體錢包，例如手機 App、瀏覽器擴充功能或網頁錢包。它們通常免費、建立速度快，也更適合：

- 日常小額轉帳
- 參與 NFT 或 DeFi
- 連接 DApp
- 進行鏈上換幣
- 管理多條區塊鏈上的資產

代價是操作環境更容易接觸到釣魚網站、惡意合約和假 App。即使錢包是自託管，私鑰仍需要由使用者自行備份與保護。助記詞遺失後，平台通常無法替你恢復；如果助記詞被別人取得，對方就可能直接控制資產。

如果只是建立錢包或收幣，通常不需要支付 OKX Wallet 的固定月費。真正容易產生費用的是鏈上交易。

目前 OKX DEX 公開的界面費率會依代幣分類而變化：

這裡有一個常見誤區：**「交易介面費」和「網路 Gas」不是同一筆費用。**

例如你在某條鏈上交換代幣，可能同時遇到：

1. OKX DEX 介面費。
2. 該區塊鏈收取的 Gas。
3. 第三方 DEX 或流動性池本身可能產生的成本。
4. 代幣價格滑點。

所以看到某個錢包寫著「免手續費」，不要直接理解成所有鏈上操作都零成本。加密貨幣的費用結構通常比便利商店買瓶水複雜一點，至少它不會在結帳前突然告訴你還要付一筆網路擁塞費。

## 冷錢包推薦：不同類型適合誰？

### 1. 硬體錢包：長期持有的首選

如果你主要持有 BTC、ETH 或其他資產，短期內不打算頻繁交易，硬體錢包通常是更合理的選擇。

選購時可以注意：

- 是否支援你的主要幣種和網路
- 是否能與常用手機或電腦連接
- 是否需要藍牙、USB-C 或 QR Code 傳輸
- 是否具備安全元件
- 是否支援多重簽名
- 是否有清楚的官方恢復流程
- 官方韌體與 App 是否持續更新
- 是否能在官方網站直接購買

OKX 的硬體錢包指南列出 Keystone、Ledger、Trezor、Ellipal 等多種硬體錢包，並說明硬體錢包通常比較適合長期保存資產；但它們需要實體操作，價格也會依品牌與功能不同而變化。

### 2. 自託管軟體錢包：適合鏈上使用

如果你需要連接 DApp、使用 NFT、進行 DeFi 或經常操作多條公鏈，OKX Wallet 的便利性會比較高。

官方目前將 OKX Wallet 定位為多鏈自託管錢包，支援資產儲存、Swap、鏈上交易、質押、NFT 和 DApp 連接等功能，也支援透過助記詞或私鑰管理錢包。

它比較適合：

- 剛開始接觸 Web3 的使用者
- 需要管理多條鏈的人
- 經常進行小額鏈上操作的人
- 想從單一介面使用 DEX、NFT 和 DeFi 的人

但不建議把所有長期資產都放在同一個手機錢包裡。手機遺失、惡意 App、假網站和助記詞外洩，都可能造成不可逆的資產損失。

- 將資產提到自己的錢包

- 交易所：放準備交易或等待提領的資產。

## 如何把 OKX 和硬體冷錢包搭配？

一個比較穩妥的流程如下。

### 第一步：硬體錢包只從官方渠道購買

不要購買已拆封、來源不明或二手的硬體錢包。硬體錢包的安全性不只取決於品牌，也取決於設備是否被動過手腳。

收到設備後，檢查：

- 外盒是否完整
- 設備是否要求你使用預先提供的助記詞
- 官方 App 是否能辨識設備
- 是否需要自行生成新的助記詞
- 韌體更新是否來自官方渠道

如果設備附帶一組「已經生成好的助記詞」，不要使用。正常流程應該由設備在初始化時自行生成，使用者再以紙本或金屬備份保存。

### 第二步：先備份，再轉入少量資產測試

助記詞不要截圖、不要放在雲端記事本、不要寄到自己的電子郵件，也不要輸入任何網站。

可以考慮：

- 手寫兩份，分開放置
- 使用防火材質或金屬備份板
- 避免把備份和硬體錢包放在同一個位置
- 不要告訴別人完整助記詞
- 不要把助記詞輸入所謂「客服驗證頁」

建立完成後，先轉入小額資產，確認收款地址、網路和提幣流程都正確，再處理較大金額。

### 第三步：從 OKX 提幣到自己的錢包

從交易所提幣時，最需要小心的是**網路選擇**。

例如：

- ERC-20 的 USDT 和 TRC-20 的 USDT 不是同一條網路。
- Arbitrum 上的 ETH 和 Ethereum 主網 ETH，在手續費與地址使用情境上不同。
- 收款地址正確，不代表選錯網路也能安全到帳。

OKX 官方說明指出，交易所提幣會涉及提幣費，而實際費用可能因網路與資產不同而變動；Web3 錢包則需要使用者自行準備對應網路的主網幣支付 Gas。

## 冷錢包使用上最容易犯的錯

### 把助記詞當成登入密碼

助記詞不是普通密碼，而是錢包的最高權限憑證。任何人取得它，都可能在另一台設備恢復你的錢包。

### 只備份設備，不備份助記詞

硬體錢包壞掉、遺失或被重置，不代表資產消失；只要助記詞安全，通常可以在相容錢包恢復。但如果助記詞沒有備份，設備壞掉後就可能再也無法控制資產。

### 把大部分資產放在熱錢包

熱錢包操作方便，但便利性不等於適合長期存放全部資產。可以把它想成日常錢包，而不是銀行保險箱。

### 忽略地址與網路確認

轉帳前至少核對：

- 收款地址前幾位與後幾位
- 幣種
- 區塊鏈網路
- Memo 或 Tag 是否需要填寫
- 實際到帳金額
- 提幣費用

### 只看「支援幾千種幣」

支援數量不是唯一標準。你真正需要確認的是：自己的幣種是否能在硬體設備上生成地址、是否能安全簽署交易、是否能透過官方 App 或相容錢包操作。
